# 快闪榜单开场

![动效预览](preview.gif)

- **类型**：开头 · 自己视频里已使用
- **风格**：黑金、科技感、信息密集、快节奏
- **适合**：工具盘点、产品榜单、多个功能介绍、快速吸引注意力
- **规格**：5.20秒 · 9:16 · 1080×1920
- **预览**：下载仓库后打开 `index.html`，可播放、暂停、重播和拖动进度；[高清MP4](preview.mp4)

GIF与预览只展示动效主体，不带示例口播人物和字幕；实际导出的画幅仍由配置决定。

## 镜头顺序

|时间|动作|
|---|---|
|0–2.0秒|每6帧切换一组素材，编号先到，名称随后出现|
|2.0–2.95秒|卡片从不同方向进入并归位|
|2.95–3.5秒|停留在完整榜单总览|
|3.5–5.2秒|突出目标卡片，其余区域压暗|

## 替换内容

修改 `config.json`，素材放进 `assets/`；先复制实例，再改内容。

|替换什么|字段|怎么改|
|---|---|---|
|榜单主题|`heading / subheading`|改成新视频标题|
|每张卡片|`items`|替换图片、名称和编号；当前10槽|
|口播与人物|`captions / audio / presenter / show_presenter`|换成新素材，或关闭人物窗口|

## 怎么用

告诉AI：“从仓库选用 **快闪榜单开场**，文案是……，素材在……，画幅是……，先给动态预览。”

- `index.html`：统一预览播放器；下载后直接打开即可看视频。
- `scene.html`：可编辑动画；通过本地HTTP服务预览时可实时拖动。
- `config.json`：替换内容。导出和运行依赖见[仓库首页](../../../README.md)。
