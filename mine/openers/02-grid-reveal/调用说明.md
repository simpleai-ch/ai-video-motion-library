# 联发九宫格（九宫格展开-01）

保存规格：16:9 · 7.33秒 · 2688×1512 原生高清。来源版本：2026-11-18 最终修订版 opening_clean.py / 无后加网格线。

动效：首图独立停留3帧；中心格先展开，周边依次揭示；九格拼成整画面；中间横条扩展；大相框铺满后向下掉落。

## 直接调用

调用「九宫格展开-01」。换成本次的封面、标题、9路格子视频及5路整画面素材。保留首图3帧、中心向外展开、中条扩展和相框掉落的顺序，默认输出16:9、2688×1512，不加九宫格白色分割线。

## 可替换项

编辑 config.json。先复制实例再改，原模板保留。

cover/cover_crop：首图与裁切；title/title_position：仿宋标题与位置；center_title：中心格文字；clips：9路格子g0–g8（同时作为高清相框素材）及lead/base/whole/walk/next共5路整画面；cover_hold_frames：首图停留；audio：声音。各视频用file与start指定，替换片段保留count和输出尺寸可沿用时间轴。
本版直接读取库内原生高清片段，不依赖旧版JPEG缓存或1080P代理。grid_lines默认false；相框自身的白边保留，不属于九宫格分割线。宽高按同一16:9比例调整；默认2688×1512。

## 操作

1. 运行库根目录 library.py new，产生独立实例。
2. 把新素材放进实例 assets，修改 config.json。音频与字幕必须随新文案替换，不能沿用示例中的产品结论或客户名称。
3. 运行 library.py validate 检查素材路径，再运行 library.py render 导出 rendered.mp4。
4. 检查构图、节奏、字幕及音画同步后，作为新片开头使用。

reference 保存原始工程快照；preview.mp4 是原确认版预览，rendered.mp4 是通过独立模板导出的验证视频。模板提供动效复用，素材权利、字幕准确性、其他画幅适配仍需按新项目检查。

依赖：本机Python/Pillow、FFmpeg；快闪另外使用Node、Playwright、Chrome。路径按本机安装配置，可通过FFMPEG环境变量调整FFmpeg。
