# 九宫格纪实开场

![动效预览](preview.gif)

- **类型**：开头 · 自己视频里已使用
- **风格**：纪实、活动回顾、多画面拼贴、相框
- **适合**：培训活动、企业活动、入企服务、vlog、现场回顾
- **规格**：7.33秒 · 16:9 · 2688×1512
- **预览**：下载仓库后打开 `index.html`，可播放、暂停、重播和拖动进度；[高清MP4](preview.mp4)

## 镜头顺序

|时间|动作|
|---|---|
|0–0.10秒|首图与仿宋标题独立停留3帧|
|0.10–1.43秒|中心格先展开，周边格子依次揭示|
|1.43–3.03秒|九个格子逐步拼成同一幅整画面|
|3.03–5.53秒|切换现场镜头，再从中间横条向上下展开|
|5.53–6.33秒|多画面交替填入格位|
|6.33–7.33秒|大相框铺满，随后向下掉落接正文|

## 替换内容

修改 `config.json`，素材放进 `assets/`；先复制实例，再改内容。

|替换什么|字段|怎么改|
|---|---|---|
|首图与标题|`cover / title / title_position`|替换封面、客户名称和标题位置|
|九宫格素材|`clips.g0–g8`|换成9路格子视频|
|整画面与相框|`clips里的其他5路素材`|按现有长度准备新视频；高清相框从原视频取帧|

## 怎么用

告诉AI：“从仓库选用 **九宫格纪实开场**，文案是……，素材在……，画幅是……，先给动态预览。”

- `index.html`：统一预览播放器；下载后直接打开即可看视频。
- `render.py`：可编辑渲染工程；播放器展示的是已导出视频。
- `config.json`：替换内容。导出和运行依赖见[仓库首页](../../../README.md)。
