# 胶片照片谢幕

![动效预览](preview.gif)

- **类型**：结尾 · 自己视频里已使用
- **风格**：复古胶片、黑底、纪实、克制、温暖
- **适合**：活动总结、企业培训回顾、纪录片收尾、照片回顾、品牌谢幕
- **规格**：3.60秒 · 16:9 · 2688×1512
- **预览**：下载仓库后打开 `index.html`，可播放、暂停、重播和拖动进度；[高清MP4](preview.mp4)

## 镜头顺序

|时间|动作|
|---|---|
|0–0.15秒|黑底与右侧胶片条建立画面|
|0.15–约1秒|左侧两行文案逐字打出|
|全程|右侧照片循环向上滚动|
|3.2–3.6秒|整体淡出收尾|

## 替换内容

修改 `config.json`，素材放进 `assets/`；先复制实例，再改内容。

|替换什么|字段|怎么改|
|---|---|---|
|左侧文案|`lines`|替换两行收尾文案|
|胶片照片|`photos`|替换照片列表|
|胶片标签与字体|`film_top / film_bottom / font`|换成项目名称与可用字体|

## 怎么用

告诉AI：“从仓库选用 **胶片照片谢幕**，文案是……，素材在……，画幅是……，先给动态预览。”

- `index.html`：统一预览播放器；下载后直接打开即可看视频。
- `render.py`：可编辑渲染工程；播放器展示的是已导出视频。
- `config.json`：替换内容。导出和运行依赖见[仓库首页](../../../README.md)。
