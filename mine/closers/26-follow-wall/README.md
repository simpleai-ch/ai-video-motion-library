# 照片墙关注结尾

![动效预览](preview.gif)

- **类型**：结尾 · 自己视频里已使用
- **风格**：暗色、个人品牌、封面墙、轻互动
- **适合**：引导关注、账号收尾、个人IP、教程结束
- **规格**：4.47秒 · 9:16 · 1080×1920
- **预览**：下载仓库后打开 `index.html`，可播放、暂停、重播和拖动进度；[高清MP4](preview.mp4)

## 镜头顺序

|时间|动作|
|---|---|
|0–0.53秒|头像、对勾贴纸和手指一起从下方升起|
|约0.73秒|点击提示音出现|
|0.53–4.47秒|头像停在中央，手指循环点击，封面墙反向错行移动|

## 替换内容

修改 `config.json`，素材放进 `assets/`；先复制实例，再改内容。

|替换什么|字段|怎么改|
|---|---|---|
|背景封面墙|`wall_images`|替换封面图片列表|
|头像|`avatar`|填入新头像路径；留空保留示例头像|
|暗度与入场|`wall_opacity / rise_frames`|默认0.24及16帧，可按视频调整|
|手指与对勾|`foreground_frames`|已保存为透明帧；替换动作须维持对应位置|

## 怎么用

告诉AI：“从仓库选用 **照片墙关注结尾**，文案是……，素材在……，画幅是……，先给动态预览。”

- `index.html`：统一预览播放器；下载后直接打开即可看视频。
- `scene.html`：可编辑动画；通过本地HTTP服务预览时可实时拖动。
- `config.json`：替换内容。导出和运行依赖见[仓库首页](../../../README.md)。
