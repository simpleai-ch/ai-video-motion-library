# 梯形弹窗铺屏

![动效预览](preview.gif)

- **类型**：开头 · 已制作，尚未确认用于成片
- **风格**：浅色、层叠、社交信息流、快节奏
- **适合**：评论展示、观点集中出现、需求很多、消息刷屏、信息爆发
- **规格**：4.00秒 · 9:16 · 1080×1920
- **预览**：下载仓库后打开 `index.html`，可播放、暂停、重播和拖动进度；[高清MP4](preview.mp4)

## 镜头顺序

|时间|动作|
|---|---|
|0–1.5秒|卡片由上到下错峰弹出，形成梯形|
|1.5–2.6秒|向两边补齐，后来的卡片遮住前面的卡片|
|2.6–4.0秒|保持铺屏状态|

## 替换内容

修改 `config.json`，素材放进 `assets/`；先复制实例，再改内容。

|替换什么|字段|怎么改|
|---|---|---|
|卡片文案与姓名|`lines / names`|替换为自己的评论或信息|
|卡片位置与速度|`pos / starts`|保留默认梯形，或调整开始时间|
|配色|`colors`|替换头像与卡片点缀颜色|

## 怎么用

告诉AI：“从仓库选用 **梯形弹窗铺屏**，文案是……，素材在……，画幅是……，先给动态预览。”

- `index.html`：统一预览播放器；下载后直接打开即可看视频。
- `scene.html`：可编辑动画；通过本地HTTP服务预览时可实时拖动。
- `config.json`：替换内容。导出和运行依赖见[仓库首页](../../../README.md)。
